About SlashFrame

SlashFrame is a free, open-source AI image prompt generator. It turns a short idea plus slash commands like /storm, /85mm or /16:9 into a finished prompt for Midjourney, Flux, Stable Diffusion, ChatGPT, Gemini, Google Flow and Kling.

How it works

You type a subject and add slash commands. Each command stands for a piece of prompt wording: /storm becomes "violent storm, dark roiling clouds, lightning, wind", /85mm becomes a portrait-style lens look, /16:9 sets a widescreen ratio. SlashFrame puts everything in a sensible order, resolves clashes and formats the result for your chosen tool.

There are over 400 commands covering camera and lens, lighting, weather, style, color, portrait, product photography, aspect ratios, negative prompts and presets. Browse them all on the cheat sheet.

What it runs on

The website runs entirely in your browser. Your text is never sent to any server. The only network request the page makes is to the GitHub API to show the public star count. There is no account, no tracking and no cookie banner.

The source code is on GitHub under the MIT license. It also ships as a Claude skill and plugin, ChatGPT and Gemini instruction packs, and ComfyUI nodes.

Who built it

SlashFrame is built and maintained by Geevarghese K Thomas, a developer focused on making AI tools more accessible. The project is open source and welcomes contributions on GitHub.
